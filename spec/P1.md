# Spec Part 1
**P1 Intake.** Modes: file upload (primary), YouTube URL (bonus), demo library. ffprobe validate (max ~3 h, 2 GB), sha256 cache. Audio 16 kHz mono wav; 720p H.264 faststart proxy MP4 served with signed short-lived URL + HTTP Range. yt-dlp: 3 retries + backoff, optional cookies env. Stages: queued, fetching, audio, transcript, frames, ocr, vision, docs, embed, ready_text, ready_full, failed. Usable at ready_text. If YouTube download fails: captions-only (`visual_unavailable=true`), message "Upload the video file to enable screen understanding".
