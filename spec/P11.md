# Spec Part 11
**P11 Interview.** Inputs: resume PDF text, role, optional JD, type (technical/HR/mixed), duration (10/20/30), level, covered chunks <= learner progress (incl. screen). State machine: plan 3-5 topics -> ask one question -> evaluate answer to JSON (scores: technical, communication, problem solving, structure; evidence quoted from candidate answer; gaps) -> decide follow-up / clarify / next topic -> end at limit or stop. Overall score = weighted average computed in code (weights in config). Feedback: strengths, improvements, preparation tips linked to lecture timestamps. Cost estimator for 10/20/30 min from configured prices. Caps: 10 min / ~8 turns in $0 mode, token caps, stop button, optional voice (Web Speech) with text fallback. Resume/JD are data (injection defence).
