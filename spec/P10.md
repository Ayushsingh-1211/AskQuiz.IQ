# Spec Part 10
**P10 Eval.** >= 40 labelled questions with pause time, gold chunk(s), expected behaviour. Scenarios: before pause (correct+cited); taught later (refuse, zero spoilers); PDF/PPT (page cite only if unlocked); not present anywhere (refuse); 3-turn follow-ups (earlier-time history dropped); screen-only/silent teacher; "this/here" uses pause frame; earlier visual via screen index; pause at 0:10; long 1-2 h video; face only (no info). Targets: spoiler leak 0 (hard gate); citation accuracy >= 90%; hallucination on unanswerable 0-5%; recall@8 >= 85%; report median/p95 latency, cost/query, Hinglish WER (measured). Dataset: 3 core videos (talking teacher, slides, code), board video, Hinglish clip, 1 PDF, 1 PPT, notes. `python eval/run_eval.py` writes `eval/results.md`.
