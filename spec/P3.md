# Spec Part 3
**P3 Screen.** Candidate every 2 s low-res; keep if phash changed enough OR OCR added enough new words; min gap 5 s; heartbeat at least every 60 s; keep last settled frame before change; cap ~300 frames/h. OCR (eng+hin) every kept frame, store confidence. Vision-describe (small model) only if OCR thin or diagram/handwriting; cap ~100 per video. Screen chunk: visible_from_s = timestamp, text = OCR + description, frame_path. Pause frame: extract exact frame at pause_t on the server with ffmpeg; always send it. Low OCR confidence: warn, never guess. No stored video: skip frames, say so.
