# Spec Part 5
**P5 TAC.** (1) all retrieval uses the SQL filter; (2) the speech chunk straddling the pause is NOT retrieved, its watched part enters only via recent window trimmed at the exact word; (3) chat history TAC-safe: messages store pause_t, drop messages made at later time than current pause_t; (4) precomputed 5-min summaries only if window ended <= pause_t, partial window summarised on demand; (5) `assert_no_future(context_pack, pause_t)` fails requests in tests and logs in prod.
